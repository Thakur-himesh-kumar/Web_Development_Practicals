What is HTML?

HTML stands for HyperText Markup Language. It is the standard language for creating web pages and describes the structure of a webpage using elements.

What is CSS?

CSS stands for Cascading Style Sheets. It describes how HTML elements are to be displayed on screen, paper, or in other media.

What is JavaScript?

JavaScript is a programming language that lets you implement complex features on web pages — updating content, controlling multimedia, animations, etc.
